# Ticket Overview

現在、ダンジョン内の階段は機能的には実装されているが、3D視点での視覚的表現が不十分で、プレイヤーが階段の存在を直感的に認識することが困難な状態。
現在のPropRendererによる階段描画を強化し、より明確で視覚的に認識しやすい3D表示を実装する。

## 現状の問題
- 階段の3D表示が目立たず、プレイヤーが見つけにくい
- 上り階段、下り階段、地上への出口の視覚的区別が不明確
- 距離に応じた適切なサイズ感が不足
- プレイヤーが現在階段上にいる場合の強調表示が不十分

## 求められる改善
- より明確で認識しやすい階段の3D描画
- 階段タイプごとの視覚的差別化（色、形状、アイコン等）
- 距離に応じた適切なパースペクティブとサイズ調整
- プレイヤー位置での強調表示の改善
- 周囲との視覚的コントラストの向上
