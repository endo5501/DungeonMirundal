# Ticket Overview

現在のダンジョンミニマップは基本的な構造（壁、床、プレイヤー位置）を表示しているが、階段の位置が明示されていないため、プレイヤーが階段を見つけるのが困難な状況。
階段システムの実装が完了したので、ミニマップ上で階段位置を明確に識別できるよう表示機能を追加する。

## 現状の問題
- ミニマップ上で階段位置が視覚的に区別されない
- 上り階段、下り階段、地上への出口の位置が分からない
- プレイヤーが階段を探すのに時間がかかる
- ダンジョン探索の効率が悪い

## 求められる改善
- ミニマップ上での階段位置の明確な表示
- 階段タイプごとの視覚的差別化（記号、色、アイコン等）
- プレイヤーがいる階段の強調表示
- 分かりやすく直感的なシンボル設計
